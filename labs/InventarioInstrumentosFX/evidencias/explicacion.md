El proyecto utiliza una arquitectura por capas bien delimitada. La interfaz en JavaFX se gestiona mediante los Controllers (ListadoController y FormularioController), los cuales se encargan exclusivamente de la interacción con el usuario y la captura de eventos. La lógica de negocio y las validaciones de duplicados o campos vacíos residen en el Service (InventarioService). La persistencia se delega al DAO (JsonInstrumentoDao), garantizando que los controladores no accedan directamente al sistema de archivos. Para la conservación de datos, se utiliza la serialización, que transforma la lista de objetos Java a formato JSON, y la deserialización, que recupera los datos del archivo JSON para reconstruir los objetos en memoria al reiniciar la aplicación
